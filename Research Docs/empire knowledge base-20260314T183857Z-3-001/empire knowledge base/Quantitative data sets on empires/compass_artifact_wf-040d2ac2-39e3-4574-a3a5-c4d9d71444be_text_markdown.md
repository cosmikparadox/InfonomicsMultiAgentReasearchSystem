# Data Gaps and Limitations

The following data **cannot be found** or remain **highly contested**:

1. **Roman Rise-period GDP**: No quantitative estimates exist for 264-27 BCE.
2. **Byzantine Rise-period GDP**: Pre-Justinianic economic quantification unavailable.
3. **Decline-phase GDP trajectories**: Only qualitative contraction documented; no numerical series.
4. **Black Death Byzantine-specific mortality**: No quantified data despite 61 documented outbreaks.
5. **Precise battle won/lost ratios**: Not compiled systematically for either empire.
6. **Byzantine frontier lengths**: General estimates only; no UNESCO-level documentation like Roman limes.
7. **Mint output volumes**: Fragmentary for both empires.
8. **Agricultural output beyond grain**: Limited to annona data for major cities.
9. **Justinianic Plague true mortality**: Active scholarly debate between maximalists (25-50%) and revisionists (minimal impact).
